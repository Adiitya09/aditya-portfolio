Data Workflow

How I Work With Data

A structured, repeatable approach that turns ambiguous datasets into clear narratives.

01

Collect

Identify and gather data from relevant sources — structured databases, CSVs, APIs, or web sources. Understand what each field represents and what questions it can answer.

02

Clean

Handle missing values, remove duplicates, standardize formats, and validate data types using Python and Pandas. Solid cleaning is the foundation of reliable analysis.

03

Explore

Run exploratory data analysis (EDA) to understand distributions, correlations, and anomalies. Use Matplotlib and Seaborn to spot patterns before deeper analysis.

04

Analyze

Apply groupby aggregations, SQL queries, DAX measures, or statistical methods to extract meaningful signals from the data. Ask focused questions and let the data answer.

05

Visualize

Build interactive dashboards in Power BI or create precise charts using Matplotlib. Every visual is designed for clarity — the chart serves the insight, not the other way around.

06

Communicate

Present findings in a format that non-technical stakeholders can act on — clear summaries, annotated dashboards, and concise data narratives that drive decisions.

SQL Capability

Writing SQL That Answers Questions

A technical showcase demonstrating analytical SQL patterns I work with.

sales_analysis.sql 
-- Top categories by total revenue
SELECT
    category,
    COUNT(order_id)    AS total_orders,
    SUM(revenue)       AS total_revenue,
    ROUND(
        AVG(revenue), 2
    )                  AS avg_order_value,
    RANK() OVER(
        ORDER BY SUM(revenue) DESC
    )                  AS revenue_rank
FROM sales
WHERE
    order_date BETWEEN
        '2024-01-01' AND '2024-12-31'
    AND status = 'completed'
GROUP BY category
HAVING COUNT(order_id) > 50
ORDER BY total_revenue DESC
LIMIT 10;
